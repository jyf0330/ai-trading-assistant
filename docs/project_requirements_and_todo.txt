AI Trading Assistant
需求与未完成事项整理

生成时间:
2026-04-21

一、项目总目标
这是一个本地运行的 AI 股票辅助工具（简版）。
第一版重点包括:
1. 交易记录整理
2. AI 简单分析股票
3. AI 模拟盘
4. 简单复盘查看
5. 数据本地保存

开发原则:
1. 尽量少改第三方源码
2. 优先整合现成 GitHub 项目
3. 先做能跑的简版
4. 不承诺仓库没有明确提供的能力
5. AI 第一版先负责分析和解释，不直接做实盘自动交易

二、四个仓库的职责
1. Journedge
- 本地交易记录
- 手动补录
- 标签 / 富文本 / 截图
- 复盘统计
- 本地 SQLite 保存

2. TradingAgents
- 股票分析引擎
- 多角色分析
- 输出分析结论
- 当前已接入本地模型

3. open-paper-trading-mcp
- 模拟账户
- 模拟下单
- 持仓 / 订单 / 账户接口
- FastAPI + PostgreSQL

4. vectorbt
- 固定规则验证 / 回测底座
- 当前主要用于规则思路，不是主页面核心模块

三、当前已经完成的内容
1. 本地整合壳 app-shell
- 首页 /
- 交易记录 /records
- 行为画像 /behavior
- 股票分析 /analysis
- 模拟盘 /paper

2. 交易记录整理
- 读取 Journedge 本地 SQLite
- 新增 Journedge -> JSON / Markdown 导出脚本
- /records 页面优先读取导出结果
- 展示最近交易、账户、标签频率、基础统计

3. AI 简单分析股票
- 本地模型已接入
- 当前模型: qwen3.6:35b-a3b-q4_K_M
- /analysis 页面可触发分析
- 分析结果本地落盘
- A 股代码会自动分流到壳层 A 股分析路径

4. AI 模拟盘
- open-paper-trading-mcp 已经整理到可启动、可初始化、可读写
- 已验证链路:
  - /health
  - /accounts
  - /stock/price/AAPL
  - POST /orders/stock/buy
  - /orders

5. 固定规则模拟
- 已实现规则:
  - 10 日均线上穿 50 日均线 -> 买入
  - 10 日均线下穿 50 日均线 -> 卖出
- /paper 页面可执行规则
- 本地规则账户会记录订单和持仓摘要

6. 行为画像 / 操盘习惯分析
- /behavior 页面已完成轻量版
- 汇总:
  - 行为事件数
  - A 股 / 美股事件数
  - 关注最多的标的
  - 动作分布
  - 数据来源分布
  - 辅助建议
  - 最近行为事件

7. 本地保存
- Journedge: SQLite
- open-paper-trading-mcp: PostgreSQL
- app-shell:
  - 快照
  - 本地规则账户
  - 分析结果文件
  - 导出结果

8. 一键启动
- 已有项目内 BAT
- 已有桌面 BAT
- 已有 Windows 一键启动路径

四、当前已经完成但仍有边界的部分

2. 本地模型分析

3. 模拟盘
